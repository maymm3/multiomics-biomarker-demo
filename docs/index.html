From data to evidence

A workflow designed to be questioned.

Each step is readable, rerunnable, and checked automatically whenever the project changes.

  1. 01Generate

    Create the same privacy-safe cohort from a fixed seed.

  2. 02Validate

    Check schema, repeated measures, and missingness.

  3. 03Compare

    Calculate paired baseline-to-week-12 changes.

  4. 04Verify

    Test signal recovery and reproduce every output byte.

Responsible by design

Open evidence, careful boundaries.

This platform demonstrates analytical thinking and engineering quality. It does not expose participant data, recreate a previous employer's work, or claim clinical validity.
